# MobilityLab GCS v1.2.0 기술 보고서

기준 2026-11-28 · QGroundControl v5.1.5 기반 · 브랜치 `dev-1.2`. 기존 구조(QGC C++/Qt/QML + 커스텀 플러그인 `custom/`)는 그대로이고, 새 기능은 플러그인 안의 독립 모듈로 넣었습니다. QGC 원본 기능은 지우거나 줄이지 않았습니다.

## 1. 바뀐 구성요소

| 모듈 | 종류 | 역할 | 기체로 명령을 보내는가 |
|---|---|---|---|
| `MLFlightRecords` (`mlRecords`) | C++ | 비행 자동 기록(2 Hz), 기록 목록·검색·불러오기, 재생 상태 계산, PDF/CSV, 지형 기반 AGL 추적 | **아니오** — 텔레메트리 읽기와 파일 쓰기만 |
| `MLSystem` (`mlSystem`) | C++ | 비정상 종료 감지, 설정 백업·복원, 진단 보고서, 업데이트 확인·받기·검증·설치 | 아니오. 복원·설치는 시동/비행 중 거부 |
| `MLMapService.requestTerrainGrid` | C++ | 3D 지형 메시용 n×n 높이 격자(QGC 지형 질의) | 아니오 |
| `MLDemo` 지면 격자 | C++ | 데모 지면을 지형 DB 격자(31×31, 40 m)로 — 내장 시뮬레이터 안에서만 | 데모 가상 기체만 |
| `MLRecordsView.qml` | QML | 기록 화면(요약·재생·그래프·이벤트·시험 정보) | 아니오(실기체 시동 중 경고 띠) |
| `MLAcact3D.qml` | QML | 3D 지형·지면 영상·기체 유형·카메라·기록 재생 | 아니오 |
| `MLAlertCenter(.Panel).qml` | QML | 4단계 경고·이력·음성·기록 연동 | 아니오 |
| `MLProfiles.qml` | QML 싱글턴 | 기체 이름·유형·색(시스템 ID 기준, 이 PC 설정) | 아니오 — FC 파라미터를 읽거나 쓰지 않음 |
| `MLTextField.qml` | QML | 테마 입력창 | — |

**제어 경로는 바뀌지 않았습니다.** ACACT 가드(`MLAcactRuntime`)의 판단·개입·복귀 코드는 수정하지 않았고, 성능 측정용으로 `_tick()` 앞에 RAII 계측(`ML_PERF=1` 일 때만 로그)만 넣었습니다. 기록·경고·3D·보고서는 모두 읽기 전용 소비자입니다.

## 2. 비행 기록

* 시작: 어느 기체든 시동(armed) → 새 기록. 종료: 모든 기체 시동 꺼짐 후 20 s, 기체 연결 0, 또는 **데모 상태가 바뀔 때**(데모와 실기체 기록이 한 파일에 섞이지 않게).
* 위치: 설정 `MLRecords/baseDir` → 포터블이면 `data/Records` → `문서/MobilityLab/Records`. 실비행·SITL 은 `Flights/<시각>`, 데모는 `Demo/<시각>`.
* 파일: `meta.json`(종류, GCS 버전, 시작·종료, 기체 유형·펌웨어, 미션 검사 요약, 가드 기록 이름, 사용자 입력), `track.csv`(아래 열), `events.csv`(시각, 단계, 출처, 기체, 문장).
  `t,sysid,lat,lon,alt_rel,alt_amsl,agl,gs,vs,hdg,roll,pitch,batt_pct,batt_v,gps_fix,sats,hdop,link_lost,armed,acact_own,mode`
* 받지 못한 값은 빈 칸으로 쓰고 화면·보고서에서 "미기록"으로 표시합니다(0 으로 채우지 않음).
* 2 Hz 로 바로 파일에 쓰고 flush 하므로 프로그램이 비정상 종료되어도 직전까지 남습니다.
* 재생은 기록 파일만 읽습니다. 지도·3D 의 기체는 기록값이며 QGC 기체 목록과 무관합니다.

## 3. AGL(지면 위 고도)

* 정의: 기체 AMSL − 지형 DB 높이(QGC 지형 질의, 기본 Copernicus DEM). 거리 센서 값이 아닙니다.
* QGC 의 `altitudeAboveTerr` 는 첫 응답 전 0, 질의 실패 뒤에는 마지막 값을 유지합니다. 그래서 v1.2 는 기록 모듈이 기체마다 지형 높이를 직접 질의(15 m 이동 또는 10 s 마다, 캐시 우선)하고 **응답 위치와 50 m 이내·30 s 이내일 때만** AGL 을 냅니다. 그 밖에는 "—"/빈 칸.
* 음수 AGL 은 감추지 않고 주의색으로 그대로 표시합니다(GNSS/기압 고도와 DEM 의 차이, DSM 의 건물·수목 높이 때문에 실제로 생길 수 있음).
* 데모: 이륙점 AMSL 과 지면을 같은 지형 DB 에서 받아, 이륙점 밖에 착륙해도 지상 AGL ≈ 0(CI 데모 점검 `agl_on_ground_near_zero`, 허용 ±2 m — 데모 지면 격자 40 m 와 DEM 30 m 차이).

## 4. 경고

| 단계 | 예 | 표시 |
|---|---|---|
| 1 정보 | 상태 안내 | i 정보 |
| 2 주의 | 충돌 예측, 배터리 낮음 | ! 주의 |
| 3 위험 | ACACT 회피 기동, 텔레메트리 두절 | ▲ 위험 |
| 4 긴급 | 비행 중 통신 두절·배터리 15% 미만·GNSS 고정 없음, 기체 쌍 긴급 근접 | ⛔ 긴급 |

이력·기록에서 해제는 단계 0("해제 · …")으로 남습니다.

같은 키의 경고는 하나만 표시(중복 방지), 단계가 높은 것이 위. 발생·해제는 이력과 비행 기록에 남습니다. 음성은 설정한 단계 이상만, 같은 경고는 30 초에 한 번.

## 5. 3D 지형

* 높이: `MLMapService.requestTerrainGrid(lat, lon, 600|900 m, 33|49)` → QGC 지형 질의. 실패하면 평면(안내 표시).
* 영상: 화면 밖 `FlightMap`(QGC 지도 제공자 설정)을 텍스처로. 경량 모드에서는 끔.
* 범례: 영상 제공자, 지형 출처·기준점·범위, "시각화 전용", Copernicus 는 표면 모델임을 표시, "건물 데이터 없음".
* ACACT 값(이격·예측·위험 영역)은 가드 엔진이 내보낸 값 그대로 그립니다(3D 에서 다시 계산하지 않음).

## 6. 업데이트·복구

* 확인: `api.github.com/repos/4424904/MobilityLabGCS/releases` 에서 버전 번호 비교. 자동 다운로드 없음.
* 설치(Windows 설치형): 설치 파일과 `SHA256SUMS.txt` 를 받아 일치할 때만 실행, 시동/비행 중 거부, 실행 후 GCS 종료. 사용자 데이터 폴더는 설치 프로그램이 건드리지 않습니다.
* 설정 백업은 QSettings 전체를 ini 로, 복원은 검증(파일 표식) 후 다음 실행에 적용.
