## 2. SITL 시험 (Linux, AppImage)

최종 릴리스 빌드 v1.0.0-build.86 (run 45950083497)에서 9종 모두 통과했습니다. 아래 최소 이격은 그 실행의 값이고, 괄호 안은 1.0.0 개발 중 다른 실행들의 범위입니다. 시험마다 값이 달라지며, 모두 비상 이격 5.5 m 보다 큽니다. 안전 이격 12 m 아래로 내려간 것은 같은 고도에서 정면 교차하도록 만든 시험이기 때문입니다.

| 시험 | 내용 | 결과 |
|---|---|---|
| targets | 고도·속도·기수 목표 조정이 PX4·ArduPilot 에 반영됨 | ✅ 최종 빌드. 개발 중 1회는 PX4 SIH 물리 발산(지면 아래 −2 m, 착륙 모드인데 지면속도 22 m/s)으로 실패해 다시 돌렸습니다. GCS 결함은 아니며 시뮬레이터 쪽 문제입니다. |
| s7duo | 시연 구역 → S7_duo 생성·업로드·검증 → 가드 → 사전 점검 → 일괄 시작 → 동기 진행 → 착륙 | ✅ 회피 개입 D1·D2, 같은 층 최소 수평 이격 9.2 m (8.7–9.7) |
| preflight | 시연 구역 없음·방위 오류 시 업로드·일괄 시작 거부, 시동 안 걸림 | ✅ |
| user | 사용자 .plan 2개. 이륙점 30 m 오류 미션은 시작 거부, 올바른 미션은 교차 회피 후 착륙 | ✅ 최소 9.85 m (8.4–10.5) |
| gcskill | 회피 중 GCS kill -9 → PX4 Offboard 상실 페일세이프(HOLD) → 재시작 후 넘겨받지 않음 → 운용자 재개 | ✅ 종료 후 0.6 s 만에 HOLD, 최소 9.97 m (8.2–9.97) |
| linkloss | 회피 중 D2 링크 차단 → 두절 표시 → D2 HOLD → 복구 후 OFFBOARD 로 되돌아가지 않음 | ✅ D2 2.0 s 만에 HOLD, 최소 7.62 m (7.62–10.3) |
| operator | 회피 중 운용자 HOLD → 가드 즉시 양보, 재개 전까지 다시 잡지 않음 | ✅ 최소 8.92 m (8.9–10.0) |
| demo | 실기체가 먼저 연결돼 있으면 데모 시작 거부 → 데모 자동 시연 → ACACT 개입·해제 → 데모 중 실기체 연결 차단 → 종료 후 허용 → SITL 기록 없음 | ✅ 7개 항목 모두 통과. 개발 중 시험 설계 결함을 찾아 고침(4절 3번) |

## 4. 1.0.0 개발 중 찾은 결함과 조치
1. **데모 기체 명령·파라미터에 응답 없음**: 데모 링크가 MAVLink 1 로 응답하고, 같은 호출 안에서 바로 응답을 보내고 있었음. MAVLink 2 고정, 응답을 큐로 보냄.
2. **지도 회색 (CI·네트워크 관리 서비스 없는 PC)**: QGC 가 운영체제의 네트워크 상태를 모르면 타일을 모두 거절. 확실히 끊긴 경우에만 거절하도록 패치(0006).
3. **실기체가 먼저 연결된 상태에서 데모 시작**: 데모가 링크는 닫았지만 기체 목록에 실기체가 남아, 데모 사전 점검에 그 기체가 섞였음. 데모 시험이 "실패"를 내고도 작업이 성공으로 끝나 드러나지 않았음. → 실기체가 연결되어 있으면 데모 시작을 거부. 데모 시험은 두 번 실행(먼저 연결된 경우 거부 / 데모 중 나타난 경우 차단)하고, 하나라도 실패하면 작업이 실패하도록 고침.
4. **개입 사유의 CPA 시각이 예측 창 길이(6.0 s)로 표시**: 문구를 "N초 안에 X m 까지 접근 예측" 으로 바꿈.
5. **언어 전환 시 QGC 의 '재시작 필요' 창이 화면을 막음**: 화면은 즉시 다시 번역되므로 창을 띄우지 않고, 콘솔에 안내 문구를 둠.
6. **데모 PDF 머리말이 "운용 모드 기록 없음"**: "데모 (시험 기록 아님)" 으로 표시.
