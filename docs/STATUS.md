* **빌드·패키지**: Ubuntu 22.04 에서 빌드, AppImage 생성, `--simple-boot-test` 통과, 모의 기체 화면 점검.

* **SITL**: AppImage 를 Ubuntu 24.04 에서 실행했고, 기체는 PX4 v1.16.2 SIH 2대와 ArduCopter 입니다. 7종 모두 통과했습니다.

| operator | 회피 중 운용자가 D1 HOLD → 가드가 즉시 넘겨줌, 미션 재개 전까지 다시 잡지 않음 → 재개 → 착륙 | ✅ 최소 9.8 m |

## 3. 시험대에서 찾은 결함과 조치
1. **시연 구역 없이 이륙점 불일치 미션이 시작을 막지 못함**: 수정함. user 시험으로 확인.
2. **기체 초기화 중 미션 업로드 시 QGC 읽기와 경합**: 초기화 중에는 업로드를 거부하도록 수정.
3. **페일세이프 Hold 기체가 링크 복구나 GCS 재시작 후 OFFBOARD 로 복귀**: 설정점을 미션 비행 중·가드 비행 중 기체에만 보내도록 수정. gcskill, linkloss 로 확인.
4. **Windows 빌드 실패** (`custom/VERSION` 이 `<version>` 헤더와 충돌): 파일 이름 변경.
5. **SITL 시험대에서 PX4 SIH 센서 누락** ("blind land"): 시험대의 CPU 우선순위를 조정해 해결. GCS 의 결함은 아님.
