# MobilityLab GCS — 구현 현황과 검증 결과 (v1.2.0)

기준: 2026-11-28, 버전 1.2.0 (QGC v5.1.5 기반, 브랜치 `dev-1.2`). v1.1.0(브랜치 `release-1.1`, 릴리스 `v1.1.0-build.96`)과 v1.0.0 은 그대로 남아 있습니다. 이전 버전 항목은 이 문서 뒤쪽에 그대로 두었습니다.

실제로 실행해서 결과를 확인한 항목만 “검증”으로 적습니다.

| 구분 | 뜻 |
|---|---|
| **S** 시뮬레이션 검증 | GitHub Actions 에서 AppImage + PX4 SIH / ArduCopter SITL, 또는 GCS 내장 데모로 자동 실행·판정 |
| **C** 화면 확인 | 가상 화면(Xvfb, GPU 없음)에서 실제 실행 화면을 캡처해 눈으로 확인 |
| **W** Windows CI | GitHub Windows Server 2022 러너에서 설치·실행·업그레이드·제거 자동 시험 |
| **R** 실기체 · 실제 PC | **v1.2.0 에서는 하나도 하지 않았습니다.** 실기체, Windows 11 실제 PC, 실제 GPU·모니터·텔레메트리 모뎀 확인은 모두 미검증입니다. |

**CI·시뮬레이션 통과는 실제 비행 안전을 보증하지 않습니다.** 그래서 릴리스는 Pre-release(시험판)로 둡니다.

## v1.2.0 SITL 회귀 (Linux, AppImage)

릴리스 빌드의 정확한 결과는 릴리스에 첨부된 `TEST_RESULTS.md` 에 있습니다. 개발 중 실행:

| 시험 | run 46102374412 | run 46107907685 | run 46109649510 |
|---|---|---|---|
| targets | 통과 | **실패** — PX4 SIH 고장안전(“blind land”), 시뮬레이터 센서 공백 | 통과 |
| s7duo | 통과 | 통과 | 첫 실행 **실패**(PX4 SIH 고장안전, 위와 같은 센서 공백) → 같은 빌드 재실행 통과, 같은 층 최소 수평 이격 10.15 m |
| preflight · user · gcskill · linkloss · operator · modes | 통과 | 통과 | 통과 |
| demo (비행 기록 점검 포함) | 통과(기록 점검 추가 전) | 통과 — 12항목 | 통과 — 12항목 |

PX4 SIH 실패 2건은 시뮬레이터 로그에 “No valid data from Baro 0 / Compass 0 → Failsafe: blind land”가 찍힌 경우로, GCS 가 보내는 명령과 무관한 시뮬레이터 측 문제로 판단합니다. 다만 GCS 의 CPU 사용이 같은 러너의 시뮬레이터를 굶겼을 가능성은 배제하지 못했습니다(성능 보고서 참고).

## 4. 1.0.0 개발 중 찾은 결함과 조치
1. **데모 기체 명령·파라미터에 응답 없음**: 데모 링크가 MAVLink 1 로 응답하고, 같은 호출 안에서 바로 응답을 보내고 있었음. MAVLink 2 고정, 응답을 큐로 보냄.
2. **지도 회색 (CI·네트워크 관리 서비스 없는 PC)**: QGC 가 운영체제의 네트워크 상태를 모르면 타일을 모두 거절. 확실히 끊긴 경우에만 거절하도록 패치(0006).
3. **실기체가 먼저 연결된 상태에서 데모 시작**: 데모가 링크는 닫았지만 기체 목록에 실기체가 남아, 데모 사전 점검에 그 기체가 섞였음. 데모 시험이 "실패"를 내고도 작업이 성공으로 끝나 드러나지 않았음. → 실기체가 연결되어 있으면 데모 시작을 거부. 데모 시험은 두 번 실행(먼저 연결된 경우 거부 / 데모 중 나타난 경우 차단)하고, 하나라도 실패하면 작업이 실패하도록 고침.
4. **개입 사유의 CPA 시각이 예측 창 길이(6.0 s)로 표시**: 문구를 "N초 안에 X m 까지 접근 예측" 으로 바꿈.
5. **언어 전환 시 QGC 의 '재시작 필요' 창이 화면을 막음**: 화면은 즉시 다시 번역되므로 창을 띄우지 않고, 콘솔에 안내 문구를 둠.
6. **데모 PDF 머리말이 "운용 모드 기록 없음"**: "데모 (시험 기록 아님)" 으로 표시.
