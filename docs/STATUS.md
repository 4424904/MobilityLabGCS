# MobilityLab GCS — 구현 현황과 검증 결과

이 문서는 실제로 만들어 돌려 본 것만 **완료**로 적는다. 판정 기준:

| 표시 | 뜻 |
|---|---|
| ✅ 완료 | 구현했고, 아래 적은 방법으로 검증까지 끝남 |
| 🟡 검증 필요 | 구현은 했지만 아직 해당 환경(SITL/실기체/Windows)에서 확인하지 못함 |
| ⬜ 미완료 | 아직 구현하지 않음 (사유·후속 조치 기재) |

기준 소스: ACACT Guard **수정1(rev1)** — `vendor/acact_guard/rev1` (원본 zip은 `vendor/acact_guard/archives`, 이전판은 `oregon_demo`).
기반: QGroundControl v5.1.5 (원본 미수정, 커스텀 플러그인 + 최소 패치).

## 1. ACACT 통합

| 항목 | 상태 | 검증 방법 / 비고 |
|---|---|---|
| 원본 보존 (이전판·수정1·zip 2개, SHA256) | ✅ | `vendor/acact_guard/*/SHA256SUMS`, 변경표 `vendor/acact_guard/ORIGIN.md` |
| 판단 로직 C++ 이식 (core.py/config.py, DUO 설정 포함) | ✅ | `tools/acact_verify/acact_compare.py`: rev1 Python과 같은 시뮬레이터에서 매 스텝 명령·쌍 판정·제어권 비교, 폐루프 120회(스트레스·GPS 오차·통신 두절 주입 포함), 최대 차이 3.6e-15 m/s — CI 매 빌드 실행 |
| 시나리오·좌표 이식 (scenarios.py/geo.py) | ✅ | `acact_compare_missions.py`: 시나리오 270건(16,364 항목)·좌표 변환 2,000건 완전 일치 — CI |
| GCS 안에서 가드 실행/정지/상태 (터미널·별도 프로세스 없음) | ✅ (빌드) / 🟡 (비행) | Linux CI 빌드 통과. 비행 동작은 아래 SITL 항목 |
| 수정1 동기 진행 (DO 항목 건너뛰기·속도 직접 적용·MISSION_SET_CURRENT 확인/3회 재시도) | ✅ SITL | PX4 SIH 2대 S7_duo 본 시연: 동기점 전부 자동 통과(미션 47항목 끝까지), 전환 실패 0건 |
| 회피 중 미션 순서 넘기기 (Advance) | ✅ SITL | 같은 시험, 회피 6회 모두 미션 복귀 |
| 시나리오 생성·업로드·지오펜스·검증 (`load`) | ✅ SITL | GCS가 직접 생성·업로드, 읽어 와서 47개 일치 확인 |
| 시연 구역 자동 (기수 평균 방위, 20° 검사, 배치 역산 중심) | ✅ SITL | 오리건 배치로 놓은 2대에서 중심 오차 < 0.1 m, 방위 0° |
| 사전 점검 (연결·GPS·위성·배터리·MAV_SYS_ID·기수 방향·조종기·미션 이륙점·이륙 위치) | ✅ SITL (정상 경로) / 🟡 (이상 경로) | 정상일 때 통과 확인. 각 이상 상황을 일부러 만든 시험은 아직 없음 |
| 다기체 자동 인식, 비지원 기체는 장애물로만 | ✅ (빌드) / 🟡 | |
| 조종사 권한 우선 (수동 모드 기체 개입 안 함, 운용자 명령 시 제어권 반환) | 🟡 | 로직은 rev1과 동등성 검증됨, 실제 링크 위 동작은 SITL 확인 필요 |
| GCS 정지·충돌 시 안전 (Offboard 끊김 → PX4 페일세이프) | 🟡 | 설계상 보장(설정점이 GCS 타이머에서만 나감), 강제 종료 SITL 시험 미실시 |
| 이벤트·오류 로그 (CSV + 요약) | ✅ (빌드) / 🟡 | 문서 폴더 `MobilityLab/ACACT` |

**ACACT 지원 범위**: 회피 제어는 PX4 멀티콥터(OFFBOARD 속도 제어)만. ArduPilot·헬리콥터·고정익은 회피 대상(장애물)으로만 고려하고 제어하지 않는다. QGC 자체의 PX4/ArduPilot 지원은 그대로다.
