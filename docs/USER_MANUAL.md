# MobilityLab GCS 사용자 설명서

> 이 문서는 버전 1.1.0 기준입니다. 실기체 운용 전에는 반드시 **SITL → 고도 분리 리허설 → 실비행** 순서를 지키세요. 각 기능의 검증 상태는 [STATUS.md](STATUS.md)에 있습니다.

## 1. 설치

| 환경 | 방법 |
|---|---|
| Windows 설치형 | `MobilityLabGCS-installer-win64.exe` 를 실행합니다. 바탕화면과 시작 메뉴에 바로가기가 생기고, 설치가 끝나면 바로 실행할 수 있습니다. 제거는 Windows "앱 및 기능"에서 합니다. |
| Windows 포터블 | zip 을 원하는 곳(USB 포함)에 풀고 `MobilityLabGCS\bin\MobilityLabGCS.exe` 를 실행합니다. 설정·기록은 `MobilityLabGCS\data` 에 남고, 레지스트리와 사용자 폴더에는 아무것도 쓰지 않습니다. |
| Ubuntu 22.04 / 24.04 | `chmod +x MobilityLabGCS-x86_64.AppImage` 후 실행합니다. 시리얼(텔레메트리 모뎀)을 쓰려면 사용자를 `dialout` 그룹에 넣습니다: `sudo usermod -aG dialout $USER` 후 다시 로그인. |

Python, Qt, QGC 를 따로 설치할 필요는 없습니다. 터미널도 쓰지 않습니다.

## 1A. 화면 모드 (v1.1)

위쪽 바의 모드 버튼(또는 F1 · F2 · F3)으로 고릅니다. **모드를 바꿔도 비행 상태, 연결, 미션, ACACT 제어와 안전 기능은 바뀌지 않습니다.** 화면에 보이는 것만 바뀝니다(SITL 시험 "modes"로 확인).

| 모드 | 누구를 위한 화면 | 보이는 것 |
|---|---|---|
| **STANDARD** 기본 운용 (처음 실행 시 기본) | 처음 운용하는 사람, 현장 운용자 | 지도 중심. 왼쪽 **비행 준비** 패널(기체 연결 → 기체별 비행 가능/확인 필요/비행 불가와 그 이유 → 명령 대상 기체의 고도·속도·배터리·홈 거리 → 비행 전 점검·미션 계획), 지도 위 **ACACT 상태 띠**(정상 감시·충돌 예측·회피 중·임무 복귀·운용자 제어·두절과 지금 할 일), 아래 명령 바. 상세 ACACT 정보는 상태 띠의 [상세]로 펼칩니다. |
| **ADVANCED** 전문 관제 | 연구개발팀, 전문 운용자 | v1.0의 모든 패널: 비행 계기·편대 카드·기체 시스템·ACACT 상황판, 편대 레인, ACACT 콘솔, 타임라인, 3D, 분석, QGC 전체 기능, 패널 배치·분리 자유. |
| **SHOWCASE** 기술 시연 | 대표 보고, 투자사, 전시회 | 발표용 전체 화면 3D. **내장 데모**(시뮬레이션 기체 + 실제 ACACT 가드) 또는 **저장된 비행 기록 재생**만 보여 주며, 비행 조작 버튼이 없습니다. 실기체가 연결되어 있으면 들어갈 수 없고, 시연 중 실기체가 연결되면 자동으로 이전 모드로 돌아갑니다. 데모 화면에는 항상 "DEMO · 시험 기록 아님"이 표시됩니다. |

* **명령 대상**: 아래 명령 바 가운데에 명령을 받을 기체(UAV 번호·기종·비행 모드)가 기체 색으로 크게 나옵니다. 기체가 2대 이상이면 테두리가 기체 색으로 강조됩니다. 다른 기체는 위쪽 탭이나 Ctrl+Tab 으로 고릅니다.
* **시작 안내(?)**: 처음 실행하면 4단계 안내(기체 연결 → 비행 전 점검 → 미션 설정 → 비행)가 열립니다. 완료된 단계는 실제 상태를 보고 자동으로 표시됩니다.
* **환경 설정(⚙)**: 화면 모드, 테마(야간·주간·**고대비** — 야외 직사광선용, 검은 글씨·진한 선·불투명 패널), UI 배율(90–150%), 언어, 3D 그래픽 품질(자동·높음·낮음), 툴팁, 단축키를 바꿉니다. 모두 이 PC 사용자 계정에 자동 저장됩니다.
* **단축키**: F1/F2/F3 모드, F11 전체 화면, Ctrl+[ / Ctrl+] 좌우 패널, Ctrl+Shift+F 전체 기체 맞춤, Ctrl+Shift+C 명령 대상으로 이동, Ctrl+Tab 다음 기체, Ctrl+Shift+A 경고 센터, Ctrl+Shift+P 비행 전 점검, Ctrl+Shift+G ACACT 콘솔, Ctrl+Shift+T 타임라인, Ctrl+Shift+3 3D, Ctrl+Shift+R 분석, Ctrl+Shift+D 테마, Ctrl+Shift+H 고대비, Ctrl+, 환경 설정, Shift+F1 도움말, Esc 닫기. 환경 설정에서 바꿀 수 있습니다. **비행 명령(시동·이륙·HOLD·복귀·착륙·비상정지)에는 단축키가 없습니다** — 키를 잘못 눌러 기체가 움직이는 일이 없도록 두 번 누르기·길게 누르기만 씁니다.

## 2. 화면 구성 (비행 화면, ADVANCED)

```
┌ MOBILITY LAB [SIM/FIELD/DEMO] · 상태 · 비행 모드 · [UAV 탭] · 확인 버튼 · LINK GNSS BATT FC · ⚠ ☑ ☾ ▦ · UTC/KST ┐
│ [비행 계기 | 편대·기체] │        지도 (검색 · 측정 · 공급자 · HUD · ACACT 표시)        │ [기체 시스템 | ACACT] │
├ 편대 레인: 기체별 진행 · ACACT 상태 · [ACACT] [분석] ──────────────────────────────────────────────────────────┤
├ 진행 단계 · 명령 버튼 ──────────────────────────────────── 비상 정지 (2초 누름) ─────────────────────────────────┘
```

* 시작하면 **MOBILITY LAB 시작 화면**에 실제 초기화 상태(설정 복원, ACACT 엔진, 지도 공급자, 링크, 운용 모드)가 표시되고 1.5초 뒤 사라집니다. 누르면 바로 넘어갑니다.
* **좌우 패널**
  * 위쪽 탭으로 내용을 고릅니다: 왼쪽 *비행 계기 / 편대·기체*, 오른쪽 *기체 시스템 / ACACT*.
  * 안쪽 가장자리를 끌면 폭이 바뀌고, ‹ › 로 접습니다. 접힌 패널은 화면 끝의 탭으로 다시 엽니다.
  * ⧉ 를 누르면 패널이 **별도 창**이 됩니다(듀얼 모니터). 창을 닫으면 원래 자리로 돌아옵니다. ACACT 콘솔, 비행 분석, ACACT 3D 상황도도 별도 창으로 뺄 수 있습니다.
* **화면 구성(▦)**: 레이아웃 *단일 기체 / 다기체 / 지도 중심*, 표시 항목(패널, 편대 레인, 고도 단면, 지도 HUD, 위치 정보, 비행 궤적, ACACT 예측선), 테마를 고릅니다. 모든 선택은 저장되어 다음 실행 때 복원됩니다.
* **테마(☾/☀)**: 야간(실내·저조도)과 주간(야외·직사광, 흰 바탕 검은 글씨)을 바로 바꿉니다. QGC의 계획·설정 화면도 같이 바뀝니다.
* **글자 크기**: QHD·4K 화면은 처음 실행할 때 화면 배율이 자동으로 커집니다(QHD 120%, 4K 150%). 설정 › 일반 › 화면 배율에서 바꿀 수 있습니다. Windows 배율 설정도 그대로 반영됩니다.
* **편대·기체 카드**: 기체마다 고유 색, 링크, 시동, 고도·속도·방위·배터리·GNSS, 미션 진행률, ACACT 상태(회피 사유 포함)를 보여 줍니다. 누르면 선택, 두 번 누르거나 ◎ 를 누르면 지도가 그 기체로 이동합니다. [전체 보기]는 모든 기체가 보이게 맞춥니다.
* **지도 HUD**: 왼쪽 패널을 접으면(또는 화면 구성에서 켜면) 지도 아래에 선택 기체의 고도·속도·상승률·방위·홈 거리·배터리가 큰 글씨로 나옵니다.
* **색의 뜻**: 하늘색 경로·선택 · 분홍 목표값/회피 명령 속도 · 초록 정상·동작 중 · 노랑 주의 · 빨강 경고 · 보라 데모 · MOBILITY LAB 빨강은 회사 표식(상태 의미 없음). 기체 색은 상태 색과 겹치지 않는 별도 팔레트입니다.
* **두 번 누르기**: 기체를 움직이는 명령은 두 번 눌러야 실행됩니다. 전체 HOLD 는 한 번, 비상 정지는 2초 누름입니다.

### 2.1 지도 도구 (지도 오른쪽 세로 막대, 위쪽 검색창)

| 도구 | 설명 |
|---|---|
| 검색 | 위도·경도(`37.21, 126.83`), 도분초, MGRS, 장소·주소를 입력합니다. 장소 검색은 OpenStreetMap(인터넷 필요)을 씁니다. 결과를 누르면 그 자리로 가고 빨간 핀이 꽂힙니다. |
| ⤢ ◎ ⌖ | 전체 기체 맞춤 · 선택 기체로 이동 · 선택 기체 추적 켜기/끄기 |
| ★ | 비행시험장 즐겨찾기. 지도를 시험장으로 옮긴 뒤 이름을 붙여 등록합니다. 사용자 설정에 저장됩니다. |
| ↔ ▱ | 거리 · 면적 측정. 지도를 눌러 점을 찍고, 오른쪽 클릭으로 끝냅니다. 측정 중에도 끌어서 지도를 옮길 수 있습니다. |
| ◭ | 3D 지도(QGC 3D 뷰: 건물·지형 고도)로 전환합니다. |
| ◫ | 지도 공급자·유형(Google, Esri, Bing, VWorld 등 QGC 공급자 전부)과 **지도 서버 상태**. 오프라인 지도 관리로도 갑니다. |
| + − | 확대 · 축소 |

지도 서버가 응답하지 않으면 지도 오른쪽 아래에 **원인**(인터넷 없음, 시간 초과, 인증키 필요/지역 제한, HTTP 오류)과 **대체 지도 버튼**이 나옵니다. VWorld 는 인증키가 있어야 하고 한국 IP 에서만 됩니다. 키를 넣지 않았다면 기본 지도는 Esri 위성입니다.

### 2.2 통합 경고 센터 (⚠)와 비행 전 통합 점검 (☑)

* **경고 센터**: 통신 두절, 배터리, GNSS, 센서, ACACT 회피·비상 근접·충돌 예측, 다기체 비행 중 ACACT 꺼짐, 운용 모드 불일치, 지도 표시 불가를 위험도 순으로 모읍니다. 항목마다 **원인**과 **확인할 일**이 있습니다. [확인]을 눌러도 상태가 계속되는 동안은 목록에 남고(흐리게), 더 나빠지면 다시 알립니다. 종 숫자는 확인하지 않은 경고 수입니다.
* **비행 전 통합 점검**: 기체마다 통신 · GNSS · 배터리 · 기체 상태 · 펌웨어/모드 · 미션 · ACACT 7항목을 판정하고 위에 **GO / 주의 / NO-GO** 를 보여 줍니다. [점검 실행]은 ACACT 사전 점검을 다시 돌립니다.

### 2.3 미션 계획 화면

QGC 미션 편집 기능은 그대로입니다. 왼쪽 아래 패널이 추가되었습니다.

* 편집 중인 계획의 비행 거리 · 예상 시간 · 최대 거리 · 항목 수
* **다기체 미션 검사(ACACT)**: 연결된 모든 기체의 탑재 미션을 함께 검사해 기체별 거리·시간·최고 고도와 오류(시작 차단)·주의를 보여 줍니다. 편집·업로드 뒤 **[ACACT 재검증]** 을 누릅니다.
* 지도에 다른 기체의 미션이 기체 색으로, 계획 경로가 안전 이격보다 가까워지는 곳이 원으로 표시됩니다.

## 3. ACACT 운용 (편대 레인의 [ACACT])

운용 패널 탭은 **운용 · 미션 검사 · 사전 점검 · 설정 · 지원 범위** 입니다.

### 3.1 처음 한 번: 설정 탭

1. **화면 언어**: 한국어 / English 중에서 고릅니다.
2. **운용 모드**: 시뮬레이션(SITL) 또는 실비행을 고릅니다.
   * 시뮬레이션 모드에서는 실기체가 연결되면 가드가 시작되지 않습니다.
   * 실비행 모드에서는 SITL 기체가 섞이면 가드가 시작되지 않습니다.
   * 위쪽 바의 `SIM` / `FIELD` 표시가 깜박이면 모드와 연결된 기체가 맞지 않는다는 뜻입니다.
3. **배치**: 화성 헬리패드 2×2, 오리건 이륙선, 오리건 2 중에서 고릅니다.
4. **시연 구역**: 기체를 이륙 위치에 놓고 기수를 비행 방향으로 맞춘 뒤 **[기수 방향으로 자동]** 을 누릅니다.
   * 방위를 직접 넣으려면 **[입력 방위로 설정]** 을 누릅니다.
   * 기체끼리 기수 방향이 20° 넘게 다르면 거부합니다.
5. **판단·회피 파라미터, 미션 검사 한계값**: 기본값은 원본 ACACT(수정1) 값입니다. 2대일 때는 원본의 2대 전용 값을 씁니다. 바꾼 항목은 분홍색으로 보이고, [기본값 복원]으로 되돌릴 수 있습니다.

### 3.2 시나리오 비행 (원본 Guard 와 같은 절차)

1. **운용 탭 › 시나리오**: 시나리오, 본 시연/리허설을 고르고 **[업로드]** 를 누릅니다.
   * 모든 기체가 지상에 있고 시동이 꺼져 있어야 합니다.
   * 업로드가 끝나면 GCS 가 미션을 다시 읽어 와서 항목 수를 확인합니다.
2. **[가드 시작]** 을 누르면 사전 점검이 자동으로 돌아갑니다.
3. **[일괄 시작 (시동·이륙)]** 을 누르면 높은 층 기체부터 5초 간격으로 시동을 걸고 이륙합니다.
4. 동기점에서는 **자동 진행**이 켜져 있으면 모든 기체가 도착하고 5초 뒤에 다음 기동을 합니다. 꺼져 있으면 [다음 단계]를 누릅니다.
   * 늦은 기체 없이 진행하려면 [대기 기체만 출발]을 누릅니다.
5. **[전체 HOLD]** 는 즉시 모든 기체를 HOLD 로 바꾸고 가드를 일시정지합니다. **[재개]** 를 누르면 미션을 계속합니다.

### 3.3 사용자 미션 비행

1. 미션을 준비하는 방법은 두 가지입니다.
   * QGC **계획 화면**에서 기체별로 만들어 업로드합니다.
   * **미션 검사 탭**의 [불러오기]로 `.plan` 파일을 올립니다. 지오펜스도 함께 올라갑니다. [저장]으로 기체의 미션을 `.plan` 으로 저장할 수 있습니다.
2. **미션 검사 탭**: 미션이나 지오펜스가 바뀔 때마다 자동으로 다시 검사합니다.
   * **오류(빨강)**: 고도 한계, 홈에서 거리, 지오펜스 이탈, 이륙점 불일치, 이착륙 지점 간격, 같은 미션 중복, 배터리 부족. **일괄 시작을 막습니다.**
   * **주의(노랑)**: 두 기체 경로가 가깝거나 동시 출발 시 가까워짐. ACACT 가 회피하므로 비행은 가능합니다. 지도에 "예상 근접" 표시가 뜹니다.
3. 가드 시작 → 사전 점검 → 일괄 시작 순서는 시나리오와 같습니다.

### 3.4 회피 중 표시 (지도 · ACACT 탭 · 타임라인 · 3D)

* **3D 상황도 (v1.1)**: 기체가 멀티콥터·헬기 모형으로 그려지고, 텔레메트리의 기수 방향·피치·롤로 돌아갑니다. 모형은 보기 쉽게 4배 확대한 기호이며 실제 크기가 아닙니다. 계획 경로(미션 검사 결과, 얇은 선)와 실제 궤적(빨강 = ACACT가 비행한 구간)을 함께 그려 회피 전후를 비교할 수 있습니다. 시점은 기본·위·옆(고도차 확인), 확대·축소, 자동 회전, 전체 화면을 지원합니다. 가드가 정지 중이면 기체 위치·자세만 보이고 예측은 표시하지 않습니다. 기록 재생에는 자세 기록이 없어 기수를 이동 방향으로 표시합니다(화면에 적혀 있음).

* **지도**: 비행 궤적(기체 색, ACACT 가 비행한 구간은 빨강), T_LOOK 동안의 예측선과 끝점(○), 안전 링(D_SAFE 의 절반), 3초 속도 벡터, 회피 명령 속도(분홍), 기체 쌍의 현재 거리, 충돌 예측 쌍의 **최근접 예측 지점과 위험 영역**(빨강/노랑 원, "최근접 예측 4.1 m · 3.2초 후").
* **ACACT 탭(오른쪽 패널)**: 가드 상태, 현재 최근접, 위험도, 그리고 쌍마다 현재 수평 이격 · 고도차 · 예측 최소 이격 · 최근접까지 시간 · 이격 눈금(●현재 ○예측)과 판단 설명. 기체마다 단계(미션·회피 기동·미션 복귀·운용자 제어·두절), 개입 횟수, Offboard 시간, 제어권, **개입 사유**(예: "D2 기체와 3.1초 후 최소 4.2 m 예측 — 안전 이격 10 m 미만 · 고도차 0.3 m"). 모든 값은 ACACT 엔진의 실제 계산값입니다.
* **타임라인**: 충돌 예측(▲) → 회피 기동(빨간 막대) → 미션 복귀(초록) → 위험 해소(△), 링크 두절(✕), 운용자 개입을 시간축에 표시하고, 위에는 최근접 이격 그래프(D_SAFE·D_EMERG 띠)가 있어 회피 전후 이격을 비교할 수 있습니다.
* **3D 상황도**: 기체의 실제 위치·고도, 지면까지 수직선, 안전 구, 비행 궤적, 예측선, 최근접 예측 지점을 3D 로 보여 줍니다. 끌어서 회전, 휠로 확대합니다. 지도 타일이 없어도 동작합니다.

### 3.5 조종사·운용자 우선

* 조종기로 수동 모드로 바꾼 기체는 가드가 넘겨받지 않습니다.
* QGC 명령(HOLD, RTL, 착륙, 목표 조정 등)을 보내면, 가드가 비행 중이던 기체도 즉시 운용자에게 넘어갑니다. 그 기체의 미션을 다시 시작하면 가드가 다시 감시합니다.

### 3.6 비정상 상황

| 상황 | 동작 |
|---|---|
| GCS 정상 종료 | 가드가 비행 중이던 기체를 HOLD 로 바꾼 뒤 닫힙니다. |
| GCS 비정상 종료·정지 | 속도 명령이 끊겨 PX4 가 `COM_OF_LOSS_T`(1 s) 뒤 Offboard 상실 페일세이프로 들어갑니다(Hold). 그 밖의 기체는 미션을 계속합니다. GCS 를 다시 켜도 가드가 공중의 HOLD 기체를 넘겨받지 않으므로, 운용자가 확인한 뒤 미션을 재개하거나 착륙시킵니다. |
| 한 기체 링크 두절 | 이벤트 "텔레메트리 두절"이 뜨고, 그 기체는 마지막 위치·속도로 예측해 추가 여유를 두고 고려합니다. 회피 중이었다면 PX4 페일세이프(Hold)로 들어갑니다. 링크가 돌아오면 "텔레메트리 복구"가 뜨고, 운용자가 미션을 재개합니다. |
| 배터리 낮음 | 경고가 뜨고, 이번 기동 뒤 착륙을 권고합니다. |
| 가드 내부 오류 | 회피 중이던 기체를 HOLD 로 바꾸고, 오류 횟수를 기록합니다. |

PX4 파라미터는 원본 `set_params.py` 값으로 맞춰 두세요. 특히 `COM_OF_LOSS_T`, `COM_OBL_RC_ACT`, `NAV_DLL_ACT`, `COM_DL_LOSS_T` 가 중요합니다.

## 4. 비행 분석 (편대 레인의 [분석])

* **왼쪽**: 비행 기록 목록(날짜, 계획, SIM/FIELD/DEMO, 최소 이격, 개입 횟수).
* **가운데**: 위에서 본 공역 리플레이 또는 **[3D 리플레이]**. [재생], 1×/4×/16×, 진행 막대를 끌어 특정 시점으로 이동합니다. 진행 막대의 빨간 띠는 개입 구간, ▾ 는 링크 두절(빨강)·운용자 개입(파랑)입니다.
* **그래프**: 기체 간 거리(회피 구간 표시, D_SAFE·D_EMERG 선)와 기체별 **고도 / 속도 / 배터리**(1.0 이후 기록). 그래프를 누르면 그 시각으로 이동합니다.
* **오른쪽**: 자동 판정, 쌍별·기체별 통계, 개입 이력, 이벤트. 항목을 누르면 그 시각으로 이동합니다.
* **[PDF 보고서]**: MOBILITY LAB 로고·머리글·바닥글이 있는 A4 시험 보고서. 데모 기록에는 모든 쪽에 "데모 · 시험 기록 아님" 워터마크가 들어갑니다. 자동 판정은 기록 기준이며 최종 판단은 시험 책임자가 합니다.

## 4A. 데모 모드 (위쪽 바의 SIM/FIELD 표시를 누름, 또는 기체 없을 때 [데모 모드로 체험])

* 시나리오: **단일 기체 미션** · **교차 비행·ACACT 회피**(2기, 같은 고도 90° 교차) · **3기 편대·고도 분리**.
* [데모 시작] → [자동 시연 실행]: 미션 업로드 → 미션 검사 → 사전 점검 → ACACT 시작 → 일괄 이륙을 실제 운용 절차대로 진행합니다. 직접 조작(모드 변경, 미션 편집·업로드, HOLD/RTL 등)도 됩니다.
* 시뮬레이션 속도 1×/2×/4×, 기체별 **통신 두절** 시뮬레이션.
* **실기체가 연결되어 있으면 데모가 시작되지 않습니다.** 패널에 노란 안내가 나오고 [데모 시작]이 꺼집니다. 데모가 실기체 링크를 대신 끊지 않는 이유는, 비행 중인 기체의 링크를 끊는 것 자체가 위험하기 때문입니다. 기체 연결을 직접 끊은 뒤 시작하세요.
* **실기체와 분리**: 데모 중에는 UDP·시리얼 등 모든 실기체 링크가 닫히고 새 연결이 거부됩니다(링크 계층에서 차단). 지도 위 보라색 "DEMO" 띠가 계속 보입니다. 데모 비행은 SITL 검증 기록이 되지 않고, 기록·보고서에 DEMO 로 표시됩니다.
* [데모 종료]를 누르면 데모 기체가 사라지고 실기체 링크가 다시 허용됩니다.

## 4B. 비행 기록 (v1.2, 위쪽 바 ☰ 또는 Ctrl+Shift+L)

* **자동 기록**: 기체에 시동이 걸리면 기록이 시작되고, 모든 기체 시동이 꺼진 뒤 20초에 끝납니다. 따로 누를 것이 없습니다. 데모 비행은 "데모" 목록에 따로 저장되고 실비행·SITL 목록에는 나오지 않습니다.
* **찾기**: 왼쪽 위 [실비행 · SITL] / [데모]를 고르고 검색창에 시험명·장소·운용자·기체 이름을 입력합니다.
* **요약**: 기체별 시동 시간·이동 거리·최고 고도·속도·배터리·GNSS·통신 두절·ACACT 개입, 기체 쌍 최소 이격. "미기록"은 GCS 가 그 값을 받지 못했다는 뜻입니다.
* **재생**: 왼쪽 2D 지도와 오른쪽 3D 가 같은 시간 막대로 움직입니다. ▶ 재생, 배속 1–16×, [다음 이벤트 ›], 막대를 끌어 이동. 막대 위 빨강 = ACACT 가 제어한 구간, 노랑 = 통신 두절, 세로선 = 경고. **재생은 기체에 아무것도 보내지 않습니다.**
* **시험 정보 입력**: 시험명·목적·장소·운용자·방법·조건·메모와 시험 책임자 판단(적합/부적합/보류/미판정, 근거)을 적고 [저장]. 보고서에 들어갑니다. 자동 집계는 판정을 하지 않습니다.
* **보고서**: [PDF 보고서], [CSV]. 데모 기록의 PDF 에는 "데모 · 실제 시험 기록 아님" 워터마크가 들어갑니다. [폴더 열기]로 원본 파일(`track.csv`, `events.csv`, `meta.json`)을 볼 수 있습니다.
* 저장 위치는 위쪽 [변경]으로 바꿀 수 있습니다(기록 중에는 불가). 기존 기록은 옮기지 않습니다.

## 4C. 경고 단계와 음성 (v1.2)

* 단계: **i 정보**, **! 주의**, **▲ 위험**, **⛔ 긴급**(비행 중 통신 두절·배터리 15% 미만·GNSS 고정 없음·기체 쌍 긴급 근접). 색이 안 보여도 기호와 글자로 구분됩니다.
* 경고 센터(🔔) → [이력]: 발생·해제 시각. 같은 내용은 비행 기록에도 남습니다.
* 음성: 환경 설정(⚙) → 음성 경고(끔 / 긴급만 / 위험 이상 / 주의 이상), 음량, 음소거, [시험]. 같은 경고는 30초에 한 번만 읽습니다.

## 4D. 고도 표시 — AGL·DEM (v1.2)

* "AGL·DEM" = 기체 AMSL 고도 − 지형 DB 높이(QGC 지형, 기본 Copernicus). **거리 센서 값이 아닙니다.**
* 지형 높이를 받지 못하면(오프라인 등) "—"로 표시합니다. 0 으로 채우지 않습니다.
* 음수는 그대로(주의색) 보여 줍니다. Copernicus 는 건물·수목 높이가 들어간 표면 모델이고 약 30 m 격자라 건물 근처·숲에서는 실제 지면과 몇 m 다를 수 있습니다. **AGL·DEM 과 3D 지형은 안전 판단(장애물 회피·착륙)에 쓰지 마세요.**

## 4E. 환경 설정의 새 항목 (v1.2)

* **성능 모드**: 자동 / 경량(애니메이션·3D 지면 영상 끔) / 균형 / 고품질. 통신·ACACT 계산·경고·기록·안전 확인 절차는 어느 모드에서도 같습니다.
* **기체 프로필**: 시스템 ID 별 이름·유형(멀티콥터·무인헬기·탠덤 헬기·고정익)·색. 이 PC 의 표시용이며 **FC 파라미터는 읽거나 바꾸지 않습니다.**
* **백업 / 복원**: 화면 배치·즐겨찾기·프로필·단축키·QGC 설정 전체를 .ini 로. 복원은 시동 걸린 기체가 없을 때만, 다시 시작하면 적용.
* **진단 보고서**: 버전·OS·화면·설정 목록 텍스트(키·토큰·좌표 값 제거). 문제 보고 때 보내세요.
* **업데이트 확인**: 누를 때만 확인합니다. 설치는 Windows 설치형에서, SHA256 이 일치하고 기체가 모두 꺼져 있을 때만.

## 5. 실비행 전 확인 사항

1. 같은 계획을 **시뮬레이션 모드**에서 끝까지 비행해 SITL 기록을 남깁니다(설정 탭 › SITL 검증 기록).
   * 실기 현장 좌표로 SITL 을 돌리면 사용자 미션도 같은 서명이 됩니다.
2. **리허설**(기체별 층 고도 분리)로 실기체를 먼저 비행합니다.
3. **실비행 모드**로 바꾸면 SITL 기록이 있는 계획만 일괄 시작됩니다.
   * 기록 없이 진행하려면 "검증 없이 진행"을 두 번 눌러야 하고, 그 사실이 로그에 남습니다.
4. 조종기를 기체마다 한 명씩 잡고, 수동 개입을 확인합니다.

## 6. 문제 해결

* **영상이 "비디오 대기중"에서 안 바뀜**(스트림은 오는데 화면이 안 나올 때): QGC 설정 › 비디오 › "Force video decoder priority" 를 "Force software decoder" 로 바꾸고 다시 시작해 보세요. GPU 가 없는 CI 서버에서는 이 설정으로만 시험 영상이 표시되었습니다(실제 PC 에서는 미검증).

| 증상 | 확인 |
|---|---|
| 가드 시작이 거부됨 | 운용 탭 위쪽의 노란 안내를 확인합니다(운용 모드 불일치 등). |
| 일괄 시작이 거부됨 | 사전 점검 탭과 미션 검사 탭의 오류를 확인합니다. |
